EM Pooling Planner

Key in cartons per East Malaysia outlet. Outlets with the same SRA shipping code are one mall and one delivery location. The page shows which locations go SRA direct, which to pool, and which go via WH21.

Example loaded: 三佳 #426 / #427 / #442, 11 Nov 2026. Press Clear all for a new lot.
  1. Each mall is one location: the AD, BF and FE counters there share one SRA drop. Each counter keeps its own SO.
  2. A location at or above the minimum goes SRA direct, on its own. Moving stock between outlets is troublesome and costly.
  3. Locations under the minimum: tick the ones to pool in the same city. If the ticked ones reach the minimum, one drop goes to the biggest, which ITs the rest on.
  4. If they still don't reach it, those outlets go via WH21 (ADCEWHTR-O), then straight to each outlet.
